Integração com upload Java

Conecte o protótipo ao backend em Java para enviar uma foto real por multipart/form-data, registrar CAPTURA/MIDIA e refletir o resultado nas etapas de Daily Gallery e QuickShare.

MIDIA aguardando upload Daily Gallery sem item sincronizado

Selecione uma imagem e execute mvn spring-boot:run dentro de java-upload-api para ativar a integração.

Por que essas telas atendem à Etapa 3

Cada tela é apresentada dentro de um chrome de navegador mobile (com URL smartshot.jovi.app/...), reforçando que é uma aplicação 100% web rodando no navegador do celular — não um app nativo. A jornada cobre captura → IA → orientação em tempo real → pós-captura → curadoria de 24h → compartilhamento, mantendo coerência direta com o MER da Etapa 2 (T_JOV_USUARIO, T_JOV_CAPTURA, T_JOV_MODO_CAMERA, T_JOV_SUGESTAO_IA, T_JOV_ALBUM, T_JOV_GALERIA_DIARIA, T_JOV_COMPARTILHAMENTO).
